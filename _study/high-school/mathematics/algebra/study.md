# Algebra — Study Subtopics

Choose a subtopic to study.

## Introduction to Algebra
Learn the language of algebra: variables, constants, terms, coefficients, and expressions.

### Key ideas
- A variable represents a value that can change or an unknown value.
- A constant has a fixed value.
- A coefficient is the numerical factor of a term.
- Like terms have matching variable parts.

### Worked example
Simplify `3x + 5x - 2`: combine the like terms to get `8x - 2`.

### Quick review
Identify the variable, coefficient, and constant in `4x + 7`.

## Variables & Constants
A variable can represent an unknown or changing quantity, while a constant remains fixed.

### Worked example
If `x = 3`, then `4x + 7 = 4(3) + 7 = 19`.

### Quick review
Explain the difference between a variable and a constant.

## Algebraic Expressions
Expressions combine numbers, variables, and operations without an equality statement.

### Worked example
Evaluate `2a + 3b` for `a = 4`, `b = 2`: `2(4) + 3(2) = 14`.

### Quick review
Translate “five more than x” into an algebraic expression.

## Simplifying Expressions
Use the distributive property and combine like terms to write equivalent expressions in simpler form.

### Worked example
`3(x + 4) + 2x = 3x + 12 + 2x = 5x + 12`.

### Quick review
Simplify `4x + 3x - 2`.

## Linear Equations
Solve equations by applying equivalent operations to both sides while preserving equality.

### Worked example
`2x + 5 = 17` → `2x = 12` → `x = 6`. Check by substitution.

### Quick review
Solve `3x - 4 = 11`.

## Inequalities
Inequalities compare quantities using `<`, `>`, `≤`, or `≥`.

### Worked example
`-2x > 8` gives `x < -4` because the inequality reverses when dividing by a negative number.

### Quick review
Solve `x + 3 ≤ 9`.

## Study checklist
- [ ] I can identify variables, constants, coefficients, and terms.
- [ ] I can translate words into expressions.
- [ ] I can simplify expressions.
- [ ] I can solve and check linear equations.
- [ ] I can solve inequalities and reverse the sign when required.
