# Variables and Constants

## Learn
A variable can represent an unknown or changing quantity. A constant keeps the same value.

In `4x + 7`, `x` is the variable, `4` is its coefficient and `7` is the constant.

## Worked example
Evaluate `4x + 7` when `x = 3`:

`4(3) + 7 = 12 + 7 = 19`.

## Common mistake
A coefficient multiplies a variable; it is not the same thing as the variable itself.
