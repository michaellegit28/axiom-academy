# Simplifying Expressions

## Learn
Simplifying rewrites an expression in an equivalent, easier form. Combine like terms and use the distributive property when appropriate.

### Key ideas
- Like terms have the same variable part.
- Only like terms can be combined.
- The distributive property gives `a(b + c) = ab + ac`.

## Worked example
Simplify `3(x + 4) + 2x`:

`3x + 12 + 2x = 5x + 12`.

## Common mistake
When distributing a negative number, apply it to every term inside the brackets.

## Quick review
Simplify `7x + 2x - 5`.

## Check your understanding
Simplify `4(2y + 3) - y`.
