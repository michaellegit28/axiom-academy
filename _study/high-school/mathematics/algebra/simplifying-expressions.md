# Simplifying Expressions

## Study
Simplifying rewrites an expression in an equivalent form with fewer or more useful terms. The main tools are combining like terms and using the distributive property.

### Like terms
Terms can be combined when their variable parts match. For example, `3x + 5x = 8x`.

### Distributive property
`a(b + c) = ab + ac`.

### Worked example
`3(x + 4) + 2x = 3x + 12 + 2x = 5x + 12`.

## Practice
1. Simplify `7x + 2x - 4`.
2. Expand and simplify `2(3y - 5) + y`.

## Key takeaways
Only combine like terms. When distributing a negative number, apply it to every term inside the parentheses.
