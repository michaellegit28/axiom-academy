<h2>What is a linear equation?</h2><p>A linear equation has a variable whose highest power is 1. A simple example is 3x + 2 = 14.</p>
<h2>Solving equations</h2><p>Use inverse operations while maintaining equality on both sides. For 3x + 2 = 14, subtract 2 to get 3x = 12, then divide by 3: <strong>x = 4</strong>.</p>
<h2>Equations with brackets</h2><p>Expand brackets first, then collect like terms and isolate the variable.</p>
<h2>Worked example</h2><p>Solve <strong>2(x + 3) = 16</strong>.</p><ol><li>Divide both sides by 2: x + 3 = 8.</li><li>Subtract 3 from both sides: <strong>x = 5</strong>.</li><li>Check: 2(5 + 3) = 16, so the solution is correct.</li></ol>
<h2>Checking</h2><p>Substitute the solution back into the original equation. For x = 4, 3(4) + 2 = 14, so the solution is correct.</p>
<h2>Check your understanding</h2><ol><li>Solve 5x - 7 = 18.</li><li>Solve 2(x + 3) = 16.</li><li>Explain why the same operation must be applied to both sides of an equation.</li></ol>
<h2>Practice set</h2><ol><li>Solve <strong>4x + 3 = 19</strong>.</li><li>Solve <strong>3x - 8 = 13</strong>.</li><li>Solve <strong>5(x - 2) = 25</strong>.</li></ol><details><summary>Show answers</summary><ol><li><strong>x = 4</strong>.</li><li><strong>x = 7</strong>.</li><li><strong>x = 7</strong>.</li></ol></details>
<h2>Common mistake</h2><p>Do not change only one side of an equation. Equality is preserved only when the same valid operation is applied to both sides.</p>
