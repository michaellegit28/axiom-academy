## Learning objectives
Recognize surds, simplify them using perfect-square factors, perform basic operations, and rationalize simple denominators.

## What is a surd?
A surd is an exact irrational root that cannot be simplified to a rational number. Examples include $\sqrt2$, $\sqrt3$ and $\sqrt5$.

Surds preserve exact values. For example, $\sqrt2$ is more precise than a rounded decimal such as 1.414.

## Simplifying surds
Factor out perfect squares:
$$\sqrt{48}=\sqrt{16\times3}=4\sqrt3.$$
Similarly, $\sqrt{75}=5\sqrt3$.

## Multiplying surds
For non-negative radicands,
$$\sqrt a\sqrt b=\sqrt{ab}.$$
Thus
$$\sqrt2\sqrt8=\sqrt{16}=4.$$

## Adding and subtracting
Only like surds combine:
$$2\sqrt7+3\sqrt7=5\sqrt7.$$
Simplify first if necessary: $\sqrt{12}=2\sqrt3$.

## Rationalizing a denominator
A denominator containing a simple square root can be removed by multiplying by that root:
$$\frac1{\sqrt2}\times\frac{\sqrt2}{\sqrt2}=\frac{\sqrt2}{2}.$$

## Common mistakes
- Treating $\sqrt{a+b}$ as $\sqrt a+\sqrt b$.
- Combining unlike surds.
- Rounding a surd when an exact answer is required.
- Forgetting to simplify before combining terms.
