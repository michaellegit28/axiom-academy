# Axiom V1 — Current Focus

## Current phase

Axiom is currently prioritizing **visual design, information architecture, and user-friendly learning workflows**.

The real past-question ingestion and examination question-bank implementation is intentionally deferred until the learning-platform foundation is ready.

## Deferred learning-platform work

When we reach the real learning-platform phase:

- Past examination questions must remain clearly identified as real past questions.
- Examination year, exam, subject, question number, session/type, and provenance must be first-class metadata.
- Axiom-authored questions must be clearly labelled as Axiom Practice.
- The question selector should support both sources without presenting authored questions as past papers.
- Real past-question files supplied by the project owner can become the first ingestion dataset.
- Web-sourced material must be used only where redistribution/provenance permits.

## Current priorities

1. Refine application shell and navigation.
2. Improve Home as a learning workspace.
3. Refine High School Study landing and taxonomy navigation.
4. Build polished Study → Subject → Topic → Chapter flows using existing content.
5. Improve Quiz and Progress visual workflows without requiring the final question-bank implementation.
6. Strengthen responsive/mobile UX.
7. Refine light/dark visual language and spacing/typography.
8. Perform visual QA before expanding content/data systems.

## Product principle

Axiom should feel like a **calm, premium study environment**, not a collection of marketing cards or unfinished database screens.

The interface should guide the learner toward the next useful action while remaining honest about what content exists.
